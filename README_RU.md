# HAPPER Smart UI — исходники

Облегчённая оболочка для телевизора HARPER 43F660TS / Android 4.4.4 (API 19).

## Важно
- Это исходный проект Android-приложения, а не готовый подписанный APK.
- В текущей среде Android SDK/Gradle не гарантированно установлены, поэтому APK здесь не собран и не протестирован на телевизоре.
- Приложение не является прошивкой и не меняет системный раздел.
- Ярлыки YouTube/VK Видео/Кинопоиск сначала пытаются запустить совместимое приложение, иначе открывают веб-адрес. На Android 4.4 веб-сервисы могут не работать из-за TLS/сертификатов и поддержки сайта.
- Кнопка перезагрузки только объясняет, как перезапустить телевизор; обычное приложение без системных прав не может выполнить reboot.
- Системный лаунчер не отключайте.

## Сборка APK
1. Установите Android Studio на компьютер.
2. Откройте эту папку как проект.
3. Установите Android SDK Platform 33 и Android Build Tools, если Android Studio предложит.
4. Используйте JDK 11.
5. Build → Build APK(s).
6. APK обычно появляется в `app/build/outputs/apk/debug/app-debug.apk`.

Минимальный Android API — 19 (Android 4.4). Установите APK на свой риск и сначала проверьте работу мышью/пультом.

## Сборка без Android Studio (GitHub Actions)
Загрузите папку в новый репозиторий GitHub → вкладка Actions → Build APK → Run workflow → скачайте app-debug.apk из Artifacts.
